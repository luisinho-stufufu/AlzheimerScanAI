# Graphics

Store project visualizations here. Chart text, titles, axes, legends, and
captions must be in English so figures are presentation-ready. Each chart
should state its population, unit of analysis, and relevant limitations.

- `CDR_distribution.svg`: OASIS-1 unique-subject CDR distribution at baseline.
  "Missing CDR" denotes an unavailable label, not a clinical class.
- `binary_split_distribution.svg`: subject counts by binary CDR class and
  train/validation/test split, restricted to subjects with a locally available
  processed T1 volume.
