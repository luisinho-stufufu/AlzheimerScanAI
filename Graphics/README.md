# Gráficos

Guarda aquí visualizaciones generadas durante el análisis del proyecto. Cada
gráfico debe indicar qué población representa, cómo se contaron las
observaciones y qué limitaciones afectan a su interpretación.

- `CDR_distribution.svg`: distribución de sujetos únicos OASIS-1 por valor de
  CDR en la sesión base. La barra «Sin CDR» representa etiquetas ausentes y no
  es una clase clínica.
